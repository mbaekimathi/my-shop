How to show this page on your main domain

Shop websites live on the app subdomain {% if main_website_guide.app_host %} ({{ main_website_guide.app_host }}) {% endif %} as /shop/<id>/. Your main domain should hit the same Django app; when the host matches the apex you set above, / serves the selected shop catalogue.

  1. Pick the shop and enter the apex domain, then save. {% if main_website_guide.shop_name %} Currently: {{ main_website_guide.shop_name }} {% if main_website_guide.apex_domain %} on {{ main_website_guide.apex_domain }}{% endif %}. {% endif %}
  2. DNS — In your domain DNS (cPanel / registrar), point the apex {% if main_website_guide.apex_domain %}{{ main_website_guide.apex_domain }}{% else %}(your main domain){% endif %} and www to the same server that hosts {% if main_website_guide.app_host %}{{ main_website_guide.app_host }}{% else %}the app subdomain{% endif %} (same A record or CNAME alias as the subdomain).
  3. Hosting — Add the apex (and www) as an Alias or Addon Domain that uses the same document root / Passenger app as the subdomain. Do not point it at a different folder.
  4. Django hosts — If DJANGO_ALLOWED_HOSTS is a fixed list (not auto), add the apex and www. Also add {% if main_website_guide.apex_url %}{{ main_website_guide.apex_url|slice:":-1" }}{% else %}https://your-domain{% endif %} to DJANGO_CSRF_TRUSTED_ORIGINS.
  5. Check — {% if main_website_guide.apex_url %} open {{ main_website_guide.apex_url }} {% else %} open https://your-main-domain/ {% endif %} — visitors see the selected shop website. Staff keep using the subdomain for the portal {% if main_website_guide.app_origin %}({{ main_website_guide.app_origin }}){% endif %}.
